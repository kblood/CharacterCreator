# CharacterCreator

Realistic, engine-agnostic 3D character generator.
Blender (headless, MPFB/MakeHuman) builds a rigged base body with morph targets and exports a GLB plus a
JSON sidecar with per-morph joint offsets. Any engine (Three.js here; Unity/Godot/Unreal later) drives
sliders, skeleton and skin colour at runtime.

Live viewer: https://dionysus.dk/webxr/charactercreator/

## Build the assets

Requires Blender 5.2 (a portable install is fine; `<blender>` below is the path to its `blender.exe`, `<scratch>` a
work folder outside the repo) with the MPFB 2 extension installed
(see [docs/BLENDER_WORKFLOW.md](docs/BLENDER_WORKFLOW.md) for the install workaround).

```powershell
python blender\tools\fetch_mh_assets.py      # once: MakeHuman CC0 system asset pack (280 MB download) -> build\mh_assets
<blender> -b --python blender\build_base.py -- output\base_body.glb
python blender\tools\check_glb.py            # must end with CHECK OK
node tools\make_colliders.mjs               # output\body_colliders.json (cloth colliders)
node tools\cloth_check.mjs                  # optional: garment penetration report
node tools\cloth_sim.mjs trenchcoat skirt   # optional: cloth simulation numbers (8 bodies, 10 s)
node tools\cloth_integrity.mjs              # optional: visible cloth penetrations (8 outfits x 9 bodies, over the default underwear, ~12 min)
```

Writes `output/base_body.glb`, `output/base_body.joints.json`, `output/hair_<id>.glb` + `output/hair.json`,
`output/clothing_<id>.glb` + `output/clothing.json` (and a .blend snapshot in `build/blend/`). `--no-assets` builds
the old bare body with a flat material; `--no-clothing` skips the garments.
Blender output is noisy; look for the `BUILD ...` lines.

Size (2026-10-01): `base_body.glb` 7.23 MB (incl. the `_CCZONE` body-zone attribute) (92 morph targets, deltas quantised with `KHR_mesh_quantization`),
hair 1.0-2.1 MB per style, `base_body_anim.glb` 8.21 MB. The viewer loads the base + the default hair = ~8.3 MB;
other styles are fetched only when picked, which is why hair is not inside the base GLB. Garments: T-shirt
0.39 MB, jeans 0.42 MB, skirt 0.20 MB, shoes 0.85 MB, trench coat 1.01 MB, shorts 0.24 MB, long-sleeve shirt 0.61 MB,
hoodie 0.68 MB, dress 0.74 MB, jacket 0.86 MB, boots 0.70 MB, briefs 0.23 MB, panties 0.18 MB, bra 0.29 MB, each loaded when first worn (the default underwear right after the base).

## Colour tints

Tintable materials (Skin, Iris, Eyebrow, Eyelash, Hair_*) carry glTF material extras
`{"tint": {"gain": g, "default": "#rrggbb"}}` (three.js: `material.userData.tint`). Their textures are
normalised at build time to a neutral grey with linear mean `1/g` (skin per channel, the others by luminance),
so `baseColor = tint (linear) * g` renders on average exactly the picked colour while the texture keeps
its detail (pores, lips, strands, iris fibres). The GLB's own baseColorFactor is the default tint (clamped to 1).
Engines without this: set `baseColor = tint * gain` yourself (`applyTint` in `web/character.js`).

The viewer's skin shader (`web/materials.js`: wrap-lighting SSS, back-light transmission through ears/nose,
pore micro-normals, male areola tone-down) does not change this contract: it only redistributes the lit colour
or blends toward `color / gain` (the picked tint), so any skin colour keeps working. Engines that ignore it just
get the plain PBR look.

## Run locally

```powershell
New-Item -ItemType Directory -Force build\site | Out-Null
Copy-Item web\* build\site -Recurse -Force; Copy-Item output\*.glb, output\*.json build\site -Force
python -m http.server -d build\site 8000    # open http://localhost:8000/
```

(`.\deploy.ps1 -StageOnly` does the same staging.) The page needs HTTP (not `file://`) because it loads the
GLB and ES modules. For scripted tests it exposes `window.__ready` and `window.__set(id, value)` (ids: the
sliders, `skin`, `eyeColor`, `hairColor`, `browColor`, and `hair` = style id or `none`, which returns a
promise; clothing: `outfit` = ids array/comma string/null, `wear` = id, `takeOff` = slot, `clothColor` =
`{id, primary, secondary}`, `underwear` = true/false: default underwear on/off), `window.__hairState()`, `window.__clothingState()`, `window.__cloth()` (cloth stats; `.reset()`, `.manual(bool)`, `.advance(s)`), `window.__camTo(pos, target)`, `window.__view(name)`, `window.__anim` / `window.__animProbe()`, and the URL
params `?anim=walk&animT=0.3&animSpeed=1.5` (animT = seek + pause; any clip name, e.g. `jump`), `?idleVary=0|1` (`?idleSeed=n`), `?hair=long01|none`, `?outfit=tshirt,jeans,shoes,trenchcoat` (the sex's default underwear is added unless the list holds underwear; `?outfit=none` or `?outfit=` = naked), `?underwear=0`, `?cloth=0|1`, `?wind=0..1`, `?clothWorker=0`,
`?view=front|side|back|face|eyes|mouth|face34|faceSide|headBack|shoulderBack`, `?lang=en`, `?sex=male|female`, `?breast=0|1` (breast physics),
`?blink=0|1`, `?look=off|camera|mouse`, `?hairCollide=0|1` (with `?shot` blink/look default to off so screenshots
are deterministic). Sex: `__set('sex', 'male'|'female'|1|0)` (`__values().sex`); breast sliders `breastSize`, `breastFirmness`, `breastHeight`, `breastSpacing`, `breastProjection`, toggle `breastPhysics`; `window.__breast()` (+ `.reset()`) gives the physics state. More hooks: `window.__values()`, `window.__eyes` (`state()`, `weights()`, `blinkNow()`,
`gaze(yawDeg, pitchDeg)`, `hold(weights)`), `window.__hairUniforms`. Export (docs/EXPORT.md): `await window.__export(options)` -> GLB
`ArrayBuffer`, `window.__exportSettings()`, `await window.__loadSettings(settings)`, `window.__shareLink()`, `window.__exportStats()`, URL param
`?character=<base64url JSON | JSON | url.json>`.

## Tests and baking the animations

```powershell
npm test                                    # = node --test "tests/*.test.mjs" (Node >= 22; package.json). One three.js test is skipped unless THREE_DIR points at a three package
node tools/sample_clips.mjs                 # clips -> output/animations/*.json (60 fps default)
# fresh .blend of the base body into a scratch folder (never into output/), then bake:
<blender> -b --python blender\build_base.py -- <scratch>\base_body.glb --blend <scratch>\base_body.blend
<blender> -b --python blender\bake_clips.py -- --blend <scratch>\base_body.blend
node tools/check_anim_glb.mjs               # must end with CHECK OK
```

Re-run `sample_clips.mjs` + bake whenever `web/animation/clips.js` changes. Clip list, numbers, the one-shot /
idle-variation rules and how to add a clip: [docs/ANIMATION_CLIPS.md](docs/ANIMATION_CLIPS.md).
